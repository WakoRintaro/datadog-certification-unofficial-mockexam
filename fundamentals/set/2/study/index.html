Question 1

A Linux system is reporting high memory usage, but the Datadog Agent's system.mem.used metric shows a different value than the free -m command's "used" column. Why might this happen?
Show the answer and explanation

Correct answer

A. Datadog's calculation of "used" memory excludes cached/buffered memory by default.

Explanation

By default, Datadog calculates system.mem.used by taking the total memory and subtracting free, cached, and buffered memory. This is because cached memory is often readily available for applications. Standard Linux tools like free or top might include cache in their "used" calculation depending on the version and flags.

Question 34

You want to monitor the rate of errors per second. Which metric type should you use in your app code with DogStatsD?
Show the answer and explanation

Correct answer

D. Increment (Count)

Explanation

Count errors by calling increment each time one occurs. A COUNT submitted through DogStatsD is stored in Datadog as a RATE, normalized per second over the flush interval, so you get errors per second directly. A GAUGE would keep only the last value reported in each interval, so it cannot count events. A HISTOGRAM describes the distribution of values such as durations, and a SET counts unique values (such as unique users).
