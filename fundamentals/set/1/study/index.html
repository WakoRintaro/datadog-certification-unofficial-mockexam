Show the answer and explanation

Correct answer

B. They automatically calculate aggregations such as the average, count, median, 95th percentile, and max.

Explanation

Question 34

A Gauge metric is best suited for which of the following?
Show the answer and explanation

Correct answer

A. Current memory usage percentage.

Explanation

A GAUGE records a snapshot of a value at a point in time, like a thermometer reading. Current memory usage is a level that goes up and down, so it is a gauge. Requests per second and errors in the last hour count events, so they are COUNT (or RATE) metrics. Function execution time is a set of measurements whose distribution matters, so it fits a HISTOGRAM or DISTRIBUTION.

Question 35

Your application calls DogStatsD increment with a value of 5 and then 10 within the same 10-second flush interval. What total does the Agent aggregate for that interval before submitting it?
Show the answer and explanation

Correct answer

A. 15

Explanation

The Agent adds up all COUNT values received in one flush interval, so it aggregates 5 + 10 = 15. Note that a COUNT submitted through DogStatsD is stored in Datadog as a RATE: each value is normalized per second over the flush interval, so a graph shows 15 / 10 s = 1.5. To see raw totals, apply a function such as Cumulative Sum or Integral.

Question 41

You want to monitor the execution time of a database query using DogStatsD. Which metric type is most appropriate?
Show the answer and explanation

Correct answer

A. Histogram

Explanation

A HISTOGRAM (or a TIMER, which is a histogram for timing data) is designed for values such as query execution time. From the samples in each flush interval, the Agent computes avg, median, max, count, and the 95percentile, so you can see both typical and slow queries. A GAUGE keeps only the last value in the interval, so most samples are lost. "Increment" is a COUNT operation for counting events, not for measuring durations. A SET counts unique values. If you need accurate percentiles across many hosts, a DISTRIBUTION is also a good choice.
