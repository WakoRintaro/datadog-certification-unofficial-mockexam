Question 6

What is the difference between a "Hard Link" and a "Soft Link" (symbolic link) in Linux?
Show the answer and explanation

Correct answer

B. Soft links are like shortcuts that point to a filename; hard links point directly to the data (inode).

Explanation

A symbolic link (soft link) points to a path; if the original file is deleted, the link breaks. A hard link points to the underlying data (inode); if the original "filename" is deleted, the hard link still accesses the data.

You see a monitor is "No Data." A common cause is the Agent on the monitored host has stopped. What setting in the monitor determines when a "No Data" alert fires?
Show the answer and explanation

Correct answer

B. The "Notify if data is missing for more than X minutes" setting.

Explanation

The "No Data" notification setting defines the silence period after which a "No Data" alert fires. It defaults to a reasonable window to avoid false alarms from brief Agent restarts.

In Datadog, what is "Log Archiving"?
Show the answer and explanation

Correct answer

B. Forwarding ingested logs to long-term, cost-effective cloud storage (like S3 or Azure Blob) for compliance and historical analysis beyond the retention period.
