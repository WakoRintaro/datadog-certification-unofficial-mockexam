Question 1

A sysadmin notices that a Linux server's `load average` (shown by `uptime`) is consistently higher than the number of CPU cores. What does this generally indicate?
Show the answer and explanation

Correct answer

A. There are more processes competing for CPU than there are cores available, leading to queuing.

Explanation

Load average measures the number of processes in a runnable or uninterruptible sleep state. If it consistently exceeds the core count, the system is CPU-bound and processes are waiting.
