DogStatsD drops a metric message it cannot parse; it never forwards unparsed data to Datadog. The parse error is logged (at error level by default, or at debug level when dogstatsd_disable_verbose_logs is enabled) and counted as Metric Parse Errors in the DogStatsD section of datadog-agent status.
