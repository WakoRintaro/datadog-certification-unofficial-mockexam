問題 1

Linux システムは高いメモリ使用量を報告していますが、Datadog Agent の`system.mem.used`メトリクスは`free -m`コマンドの「used」列とは異なる値を示しています。なぜこのようなことが起こるのでしょうか?
正解と解説を見る

正解

A. Datadog の「使用済み」メモリの計算では、デフォルトでキャッシュ/バッファされたメモリが除外されます。

解説

デフォルトでは、Datadog は合計メモリを取得し、空きメモリ、キャッシュされたメモリ、バッファされたメモリを差し引くことによって`system.mem.used`を計算します。これは、キャッシュされたメモリがアプリケーションですぐに利用できることが多いためです。`free`や`top`などの標準 Linux ツールでは、バージョンとフラグに応じて、「使用される」計算にキャッシュが含まれる場合があります。

この問題の正解・解説について報告する
