Questão 6

Qual é a diferença entre um "Hard Link" e um "Soft Link" (link simbólico) no Linux?
Mostrar a resposta e a explicação

Resposta correta

B. Soft links são como atalhos que apontam para um nome de arquivo; hard links apontam diretamente para os dados (inode).

Explicação

Um link simbólico (soft link) aponta para um caminho; se o arquivo original for excluído, o link quebra. Um hard link aponta para os dados subjacentes (inode); se o "nome de arquivo" original for excluído, o hard link ainda acessa os dados.
